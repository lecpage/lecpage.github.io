# lecpage 예비 주소

https://lecpage.github.io/ 는 [lecpage](https://lecpage.com) 웹앱의 예비 주소예요. lecpage.com이 열리지 않을 때 같은 앱을 여기서 쓸 수 있어요.

- 이 저장소에는 앱 코드가 없어요. `.github/workflows/mirror.yml`이 2시간마다 [yoorrard/lecpage](https://github.com/yoorrard/lecpage)의 main을 받아 빌드해 GitHub Pages로 올려요. 올린 판은 `mirror.txt`에 적혀요.
- 이 조직에는 다른 Pages 사이트를 만들지 않아요. 이 주소를 lecpage 혼자 써야 lecpage 커넥트가 믿을 수 있어요.
- 운영 안내: [docs/operations.md](https://github.com/yoorrard/lecpage/blob/main/docs/operations.md) 16절
